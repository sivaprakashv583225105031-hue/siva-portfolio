Intelligent Sensor Fusion Module for Elevator Safety
View Proposal (PDF)
Designed a compact ESP32-based edge device that fuses five live sensor feeds — vibration, temperature, current, position, and door state — into a single real-time health score for elevator subsystems. Edge logic samples every 200ms and applies threshold + rolling-average checks before pushing data over WiFi (MQTT/HTTP) to a live dashboard. Built for the Smart Elevator Hackathon 2026, Hardware Track.

AI-Enabled Hybrid Wind Turbine — Clean Energy for MSMEs
View Presentation (PDF)
Proposed a hybrid wind + flexible thin-film solar system for small and medium enterprises, paired with an ESP32-based IoT sensing layer and an AI engine for real-time energy optimisation and predictive maintenance. Targeted an estimated 38% cut in annual energy cost versus grid + diesel backup. Presented for the MSME Clean-Energy Innovation Hackathon.
